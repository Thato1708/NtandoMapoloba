Goshen Business and Career Advisory Services

CMS-driven site for an advisory firm · Built solo via Pistis Technologies · 2026

Problem

Goshen Business and Career Advisory Services needed a website that explains what the firm is and what it does, and lets its team publish thought leadership and show its professional engagements without a developer.

Decisions

This needed more than a static brochure site, so I built a custom CMS in ASP.NET Core MVC, the stack I know best, which lets Goshen update content without a developer. MVC’s structure suits database-driven features, and it works well with authentication, authorization and Entity Framework Core. I organised the site around Sectors, Services, Advisory, Programmes and Insights, so visitors can see what Goshen offers. From the admin dashboard, the team can create, edit and delete insights and professional engagements, including their photos. The admin area is protected with ASP.NET Core Identity: [Authorize] on the admin controllers, hashed passwords, and a single admin role that can sign in.

Stack

  • ASP.NET Core MVC
  • ASP.NET Core Identity
  • Tailwind CSS
  • Neon PostgreSQL
  • Cloudinary

Result

Delivered and live. The client manages its own insights and engagements from the admin dashboard.

Goshen Business & Career Advisory Services, Google review

Jesus Journey Runners

Custom CMS for an NGO · Built and deployed solo · 2026

Problem

Jesus Journey Runners, an NGO, needed to publish event updates and photos without waiting on a developer, and to accept online donations.

Decisions

I built a custom CMS in ASP.NET Core MVC, the framework I know best, so I could deliver quickly and keep the code easy to maintain. Images needed care because two services share the job: Cloudinary stores the image files, while Neon PostgreSQL stores each image’s URL, caption and album link. When an admin uploads an image, the app sends it to Cloudinary through an IImageStorageService, receives the URL, assigns it to the entity and saves the record with Entity Framework Core’s SaveChangesAsync().

Stack

  • ASP.NET Core MVC
  • Tailwind CSS
  • Neon PostgreSQL
  • Entity Framework Core
  • Cloudinary

Result

Delivered and live. The client’s team can create, edit and delete events and gallery images from an admin dashboard, and visitors can donate through the site.

Emily Bakes Blog

PERN-stack recipe blog · Built and deployed solo · 2026

Problem

Emily Bakes wanted to build a subscriber list for her recipes and keep every recipe available on a permanent site, without needing a developer for each post.

Decisions

I built a PERN-stack blog with a custom admin dashboard where she writes recipes and manages images. For subscribers, I built a custom email subscription form that saves sign-ups to PostgreSQL through an Express API, so the list lives in her own database. The dashboard includes subscriber management and CSV export. I designed, built and deployed it on Render.

Stack

  • PostgreSQL
  • Express
  • React
  • Node.js
  • Render

Result

Delivered and live. Recipes and images are managed from one dashboard, and subscribers are stored in the client’s own database and can be exported as CSV.
